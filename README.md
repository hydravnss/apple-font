# Police Apple

Extension [SillyTavern](https://github.com/SillyTavern/SillyTavern) qui applique la **police Apple** (San Francisco) à l’interface, avec un choix entre texte **normal** et texte **gras**.

Pensée pour iPhone : sur Safari iOS, la police système *est* San Francisco. Testée vis-à-vis de SillyTavern 1.19.

## Installation

1. Ouvre SillyTavern → **Extensions** (icône des cubes) → **Install extension**.
2. Colle l’URL : `https://github.com/hydravnss/apple-font`
3. Valide, puis recharge la page.
4. Les réglages sont dans **Extensions → Police Apple**.

## Réglages

- **Activer** — police Apple partout (chat, champs de texte, menus).
- **Texte** — **Normal** ou **Gras**.
- **Appliquer le gras à** — chat seulement, ou toute l’interface.

Les fichiers SF Pro ne sont pas inclus (licence Apple). L’extension utilise `-apple-system` / `BlinkMacSystemFont`, qui affichent San Francisco sur iPhone et Mac. Sur un autre appareil, le navigateur prend la police système la plus proche.
